## About

This repository contains C++ implementations of computer graphics concepts covered in coursework. The codebase follows a modular structure with separate files for core graphics components like meshes, shaders, and window management.

---

## Features

- Modular C++ implementation of core graphics concepts
- Separate labs for progressive learning
- Mesh handling for 3D objects
- Shader implementation for rendering
- Window management for visualization
- CLion project configuration files
- CMake build system integration
